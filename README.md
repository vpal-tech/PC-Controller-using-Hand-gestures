PC Controller Using Hand Gestures
Project Overview
This project allows users to control their PC using hand gestures through a webcam. It is developed using Python and computer vision.
Features
Hand tracking using a webcam
Real-time hand coordinate detection
Gesture-based PC control
Keyboard and mouse interaction (depending on implemented features)
Technologies Used
Python
OpenCV
MediaPipe
Computer Vision
Installation
Clone this repository:
git clone YOUR_GITHUB_REPOSITORY_URL
Open the project folder:
cd PC-Controller-Using-Hand-Gestures
Install the required dependencies:
pip install -r requirements.txt
Run the project:
python main.py
